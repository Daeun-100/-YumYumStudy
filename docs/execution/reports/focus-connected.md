# 집중 화면 연결 — 2026-10-27

- Storybook 집중 화면의 헤더·배경·좌석 좌표·타이머 패널·달성 배지·원형 버튼을 FocusView로 추출했다. Storybook과 실제 /focus가 같은 UI를 사용한다.
- FocusScreen은 StudyProvider 서버 스냅샷을 연결한다. 실제 참여자만 최대 4개 좌석에 표시하며 본인은 첫 좌석, 친구는 UID 순으로 고정한다. 미참여 좌석은 비워둔다.
- 선택한 캐릭터 6종을 집중 화면 에셋에 연결했다. 이름과 친구 공부 시간, 진행 상태는 실제 데이터다.
- 시작/일시정지, 중복 요청 방지, 실패 시 같은 요청 재시도는 기존 StudyProvider 로직을 사용한다. 돌아가기와 친구 현황 버튼을 실제 라우트로 연결했다.
- 0번 테스트 방에서 시작 → 시간 증가 → 새로고침 후 진행 세션 복원 → 일시정지(누적 00:01:52) → 친구 목록 이동과 집중 복귀를 확인했다. 세션은 중지 상태로 남겼다.
- 기본 화면과 320×740에서 배치 확인. 실제 기기 확인은 미실시.
- lint, tsc --noEmit, 테스트 50개, Storybook 빌드 통과. 빌드는 /tmp/yumyum-focus-storybook에 생성했다.
