# 최초 목표 즉시 적용

- 목표 이력이 한 번도 없는 계정의 최초 저장은 서버 기준 현재 공부 날짜부터 적용한다. 이미 공부한 시간도 목표 달성 계산에 포함한다.
- 이후 저장은 다음 공부 날짜 한국 시간 오전 6시부터 적용한다. 목표 이력이 모두 미설정이어도 최초 설정 상태로 돌아가지 않는다.
- 프로필 행 잠금 이후 시각과 최초 여부를 판정해 동시 저장과 오전 6시 경계를 처리한다.
- 기존 목표 이력 및 예약은 변경하지 않는다.
- `270_initial_goals_today.sql`은 기존 입장 확인과 방 분리, 입력 검증, 함수 권한을 유지한다.
- 화면은 서버의 `isFirstSetup`으로 안내를 선택하고 실제 저장 응답의 적용 날짜로 즉시 적용 성공 여부를 표시한다.
- 타입 검사, 린트, 전체 테스트 62개 통과. 서버 SQL 검증은 `supabase/tests/initial_goals_today.sql`로 재현 가능하다.

- 연결된 Supabase 서버에 함수 변경 반영 완료. 새 임시 계정으로 최초 즉시 적용·오늘 조회·후속 변경 예약·초기화 후 재적용 방지를 검증했고 전체 테스트 데이터는 롤백했다.
