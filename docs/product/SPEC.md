# 얌얌스터디 제품 명세

개정일: 2026년 10월 29일

## 어떤 앱인가

얌얌스터디는 **친구와 함께 공부하는 느낌을 통해, 꾸준히 공부하고 부담 없이 쉬도록 돕는 앱**이다.

공부 시간과 목표를 같은 공간에서 나누고, 서로의 노력을 알아보며, 쉬었다가 다시 돌아오는 습관을 만든다. 새 기능은 이 경험에 얼마나 도움이 되는지를 기준으로 판단한다.

## 누구를 위한 앱인가

서로 아는 친구 4명이 함께 쓰는 소규모 스터디를 위한 앱이다. 혼자서는 공부를 시작하기 어렵고, 서로의 공부 상황을 매번 따로 묻기 번거로운 상황을 줄인다.

친구는 고정 공부방에 초대로 참여한다. Android는 APK, iPhone은 Safari 웹앱으로 사용하며 두 환경에서 목표·기록·친구 현황·연차를 함께 공유한다.

## 핵심 가치와 경험

| 핵심 가치 | 제공할 경험 |
| --- | --- |
| 함께하는 느낌 | 공부방에서 친구의 캐릭터와 공부 상태를 보며 같은 공간에 있다는 느낌을 받는다. |
| 꾸준함을 알아보기 | 스스로 정한 목표와 쌓인 기록을 통해 오늘의 노력과 지난 흐름을 확인한다. |
| 쉬고 다시 시작하기 | 연차로 쉬는 날을 정하고, 휴식 후 공부를 재개한다. |

기본 흐름은 **목표 정하기 → 함께 공부하기 → 기록 돌아보기 → 쉬고 다시 시작하기**다. 첫 입장 이후에는 복잡한 준비 없이 공부를 시작할 수 있어야 한다.

## 핵심 기능과 역할

| 기능 | 제품 안에서의 역할 |
| --- | --- |
| 공부방과 타이머 | 공부를 시작하고 시간을 쌓으며 친구와 함께하는 중심 공간이다. |
| 요일별 목표 | 각자의 생활에 맞는 공부 기준과 쉬는 날을 정한다. |
| 내 기록과 친구 현황 | 누적된 노력과 서로의 진행 상황을 확인한다. |
| 연차 | 매주 주어지는 휴식과 목표 달성 보상으로 쉬는 날을 확보한다. |
| 포스트잇과 친구 부르기 | 짧은 응원과 초대로 친구 사이의 연결을 이어간다. |
| 캐릭터와 보유 스킨 | 나를 표현하고 공부방에 애착을 느끼게 한다. |
| Android 허용앱 | 공부에 필요한 외부 앱을 사용하면서 집중 측정을 이어가도록 돕는다. |

## 제품 원칙과 주요 정책

- **시작은 간단하게:** 별도 회원가입 화면 없이 초대 확인과 이름·캐릭터 설정으로 참여한다. 공부 시작에 불필요한 권한 설정을 요구하지 않는다.
- **기록은 믿을 수 있게:** 서버 기록을 기준으로 시간을 계산하고, 저장 실패나 오래된 현황을 성공·최신 상태처럼 보여주지 않는다. 이름을 바꿔도 기록의 주인은 바뀌지 않는다.
- **내 목표를 기준으로:** 요일별 목표를 직접 정한다. 첫 설정은 오늘부터, 이후 변경은 다음 공부 날짜부터 적용해 과거 기준을 보존한다.
- **휴식도 존중하기:** 무료 연차와 목표 달성 보상 연차를 제공한다. 연차는 공부 목표를 면제하며 실제 공부 기록은 보존한다.
- **같은 날짜 기준으로:** 하루는 한국 시간 오전 6시에 시작한다. 목표·기록·출석·연차에 같은 기준을 사용한다.
- **플랫폼에 맞게:** 기본 타이머는 직접 일시정지할 때까지 유지한다. Android 허용앱 모드는 허용 경로 이탈·잠금 등을 감지하면 일시정지하고 직접 재개한다. iPhone 웹은 허용앱을 구분하지 않는다.
- **필요한 만큼만 만들기:** 소규모 친구 스터디에 필요한 기능과 운영 구조를 우선한다. 기능을 추가할 때는 꾸준함·연결감·휴식 중 어떤 가치를 높이는지 설명할 수 있어야 한다.

## 현재 범위와 하지 않는 것

현재 범위는 고정 공부방, 공부 측정, 목표와 기록 공유, 연차, 짧은 소통과 캐릭터 꾸미기다. 공개 커뮤니티, 여러 스터디방 운영, 실시간 대화방, 결제, 다른 앱 자체의 실행 차단은 포함하지 않는다.

별도 계정 로그인·기기 간 계정 복구, 오프라인 신규 공부 시작, 사용자 공부 기록 편집은 현재 제공하지 않는다. 기기나 저장소가 바뀌면 기존 기록 접근이 유지되지 않을 수 있다.

수박 재화·상점·상품 구매·플래카드는 [보상 초안](../proposals/WATERMELON-REWARDS-DRAFT.md)에서 검토하며 확정 기능과 구분한다. 이 명세는 제품 기준이며 운영 배포와 실기기 검증 완료를 뜻하지 않는다.
