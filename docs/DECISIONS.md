# 결정 기록

## 확정

- 프로젝트의 최우선 구현 원칙은 간단함이다. 현재 MVP에 필요한 최소 구조와 의존성을 사용하고 미래 확장을 위한 기능·추상화를 미리 추가하지 않는다.
- Android APK 직접 배포 + iPhone 웹앱.
- 업데이트는 앱 안에서 안내한다. 작성자가 배포 완료 후 플랫폼별 배포 정보를 활성화하고, 앱은 실행·복귀 시 확인한다. 사용 중 주기적 확인, 꺼진 앱 OS 푸시와 강제/자동 설치는 제외한다.
- Expo 공통 코드, Supabase 공유 백엔드.
- 로그인·회원가입 화면 없이 Supabase 익명 인증으로 UID를 자동 발급하고 세션을 저장한다. 이름은 표시용이다.
- 모두 작성자가 포함된 고정 방 하나에 자동 참여한다. 방 생성·검색·선택·초대·가입 승인은 제외한다.
- 예상 사용자는 4명이며 가입 인원 제한은 두지 않는다. 저장소 삭제·기기 변경 시 새 UID가 될 수 있고 MVP는 이전·복구·이름 기반 병합을 제공하지 않는다.
- 화면 이탈·잠금·앱 종료·연결 단절에도 타이머를 유지하고 직접 중지하면 종료한다. 다른 앱 사용 시간도 포함한다. (2026-10-26 변경)
- 중지는 서버 승인 시각에 확정한다. 통신 실패 시 미확정 상태와 재시도를 표시한다.
- 출석은 진행 중 시간을 포함한 해당 공부 날짜의 기록이 1초 이상이면 present다. 0초인 현재·미래 날짜는 pending, 종료된 공부 날짜는 absent다. 목표 달성과 별개다.
- 휴무(isRestDay)와 출석은 별도 값이다. 휴무일에 공부해도 출석하며, 0분·미설정 목표에는 목표 달성 여부를 계산하지 않는다. 휴무일의 공부 없음도 사실상 absent로 기록하되 불이익 규칙을 의미하지 않는다.
- 요일별 목표 0분은 휴무다. null(미설정)과 구분한다.
- 목표는 요일별 0~1,440분 정수 또는 미설정(null)을 허용한다.
- 목표 변경은 다음 공부 날짜 오전 6시부터 적용한다. 현재 공부 날짜와 과거 목표에는 영향을 주지 않는다.
- 보상 연차는 월~일 기준 한 주에 6일 목표를 달성하면 1개 지급한다. 한 주는 월요일 오전 6시부터 다음 월요일 오전 6시 전까지다. 보상 연차의 최초 지급은 없다.
- 6번째 날 목표 달성 즉시 보상 연차를 지급하며 지급 직후부터 사용할 수 있다. 당일 사용은 아래 보상 보호 조건을 따른다. 획득 주 시작 시각 + 21일이 만료 시각이며 만료 시각 정각에는 사용할 수 없다. UID+획득 주+종류(free/reward) 기준으로 중복 지급을 막는다.
- 비용과 운영 부담을 줄이되 무료 한도와 서비스 정책을 확인하며 운영.

## 연차 상태 — 2026-10-27 개정

당일 사용은 앱 소스와 DB에 구현했다. 로컬 검증 보고서는 `docs/execution/reports/same-day-leave.md`를 따른다. 앱 배포 완료를 의미하지 않는다.

- 지급 건 하나는 AVAILABLE / SCHEDULED / USED / EXPIRED 중 하나로만 반환한다.
- availableCount는 AVAILABLE 건수와 정확히 같아야 한다. 예약·완료·만료는 제외한다.
- 사용일 기준은 한국시간 오전 6시다. 현재 공부 날짜는 즉시 사용, 미래 날짜는 예약하며 과거 날짜는 사용할 수 없다. 승인 시점에 획득했고 미만료인 지급분만 사용한다. 미래 예약은 사용일 시작 시각도 만료 전이어야 한다.
- 신규 사용/예약은 AVAILABLE 지급분으로 처리한다. SCHEDULED 예약은 미래 날짜 또는 당일로 변경할 수 있다. 미래 예약은 사용일 시작 전 취소하여 AVAILABLE로 복원하며 원래 만료일을 유지한다.
- 미래 예약은 사용일 시작 정각부터 USED다. 당일 신청과 미래 예약의 당일 변경은 서버 승인 즉시 USED이며 이후 취소/변경할 수 없다. 만료 시각이 지나도 USED를 유지한다.
- 예약하지 않은 지급 건만 만료 정각부터 EXPIRED다.
- 상태는 서버 시각으로 조회 시 계산하므로 cron 없이도 앱 재진입 시 올바르게 반환한다.
- 현재 구현은 지급 건 ID를 선택하는 API다. 230에서 자동 차감 선택을 구현했다. UI는 별도 범위다.

## 연차일 출석·지급 계산 — 2026-10-26

- 미래 예약은 사용일 한국시간 06:00부터, 당일 신청은 서버 승인 후 해당 공부 날짜 전체의 출석이 leave(연차)다. 공부 기록이 있어도 연차 출석이 우선한다. 미래 예약은 미리 출석 처리하지 않는다.
- 연차 사용일은 주간 연차 지급에 필요한 6일에서 제외한다. 연차일에 실제 공부 목표를 달성해도 지급 계산에서는 제외한다.
- 실제 공부 시간과 goalAchieved는 실제 기록으로 유지한다. goalAchieved 합계만으로 연차 지급 자격을 판단하지 않는다.
- 사용자당 날짜별 연차 1개만 예약/사용할 수 있다. API 검사와 부분 UNIQUE 인덱스로 보장한다. 취소하면 해당 날짜를 다른 연차로 다시 예약할 수 있다.
- 연차 화면 보류 결정은 종료한다. 기존 화면의 당일 사용 변경은 `docs/execution/05-attendance-leave.md`를 따른다.

## 디자인 표시 기준 — 2026-10-26

- 전환 탭은 연한 바탕 + 흰색 선택 영역 + 초록색 선택 글자를 사용한다.
- 목표 달성의 대표 표시는 수박(🍉)이다. 색상이나 아이콘만으로 상태를 전달하지 않고 접근성 이름 또는 문구를 함께 제공한다.
- 달성률 숫자는 100%를 초과할 수 있다(예: 123%). 가로 막대와 원형 채움은 100%까지만 그린다. 목표 미설정·휴무는 달성률 없음으로 유지한다.
- 날짜 상태는 서로 다른 표시 영역으로 구분한다. 선택은 진한 초록 배경과 흰 날짜 숫자, 오늘은 날짜 아래 작은 점(선택 시 흰색), 일정/성과는 보조 아이콘으로 표시한다.
- 연차와 목표 달성이 겹치면 보조 아이콘은 연차 비행기를 우선한다. 실제 목표 달성은 상세 정보와 접근성 설명에 유지한다. 연차 표시가 목표 달성이나 연차 지급 자격을 뜻하지 않는다.
- 예: 오늘+선택+달성+연차 예약이 겹치면 초록 선택 배경, 흰 날짜 숫자, 흰 오늘 점, 연차 아이콘을 표시한다. 상세에서는 연차 예약과 목표 달성을 모두 설명한다.
- 선택 불가 날짜는 새로 선택할 수 없지만 오늘/연차/달성 정보는 지우지 않는다. 월 이동이나 데이터 변경으로 기존 선택이 불가능해지면 선택을 해제한다.
- 연차/기록 달력의 후속 변경에도 이 표시 기준을 유지한다.

## 당일 연차 사용 확정 — 2026-10-27

- 현재 공부 날짜는 한국시간 06:00부터 다음 날 06:00 전까지이며 서버 시각으로 판정한다. 10월 28일 02:00의 현재 공부 날짜는 10월 27일이다.
- 당일 사용은 해당 공부 날짜 전체에 적용하고 승인 시각은 별도 보존한다. 실제 공부 기록·목표 달성 여부를 유지하고 타이머를 자동 종료하지 않는다. 연차 사용 후에도 공부할 수 있다. 휴무·미설정 여부만으로 새 사용 제한을 추가하지 않는다.
- 이미 지급된 보상의 획득 조건을 깨는 당일 사용은 제한한다. 당일을 제외한 해당 주의 보상 인정 일수가 6일 미만이며 변경 전 보상을 이미 획득했거나 획득 조건을 충족했다면 거부한다. 무료/보상 중 무엇을 쓰는지와 관계없이 적용한다. 지급 조회 여부와 기존 보상의 예약/사용/만료 여부에 따라 결과가 달라져서는 안 된다.
- 보상 인정 일수는 양수 목표를 달성한 서로 다른 공부 날짜 중 연차 사용일을 제외한 수다. 당일 제외 후에도 6일 이상이면 허용한다. 보상 조회 순서로 우회하거나 이미 획득한 보상을 회수하는 방식은 사용하지 않는다.
- 보상 미획득·조건 미충족 상태에서는 당일 사용을 허용한다. 그 날짜는 이후 목표를 달성해도 보상 인정 일수에서 제외한다.
- 자동 차감은 대상 날짜에 유효한 AVAILABLE 지급분 중 만료 시각, 획득 시각, ID 순이다. 미래 예약 날짜 변경은 기존 지급분을 유지하고 실패하면 기존 예약을 보존한다.
- 당일 낮에 획득한 지급분도 보상 보호 조건을 만족하면 당일 사용할 수 있다. 사용일 06:00이 획득 시각 이후여야 한다는 기존 DB 제약을 승인 시각 기준으로 변경했다.
- 확인 중 공부 날짜가 바뀌면 새 날짜를 자동 적용하지 않는다. 날짜와 상태를 갱신하고 다시 확인받는다. 서버 승인 전 통신 실패를 성공으로 표시하지 않으며 같은 요청 재시도로 중복 차감을 막는다.
- 무료 연차는 매주 월요일 06:00에 1개 지급하고 다음 월요일 06:00 정각 만료하며 이월하지 않는다. 자동 지급은 2026-11-02 06:00부터 시작하고 2026-10-26 주간분은 별도 지시 전 지급하지 않는다.
- 기존의 6일 달성·최초 지급 없음·획득 주 시작+21일 만료는 보상 연차 규칙이다. 지급 중복 방지는 사용자+획득 주+종류(free/reward) 기준이다. 이번 변경으로 지급·만료 정책은 바꾸지 않는다.

## 불투명 UI — 2026-10-26

- 앱의 버튼·카드·탭 등 UI 표면은 불투명 단색으로 통일한다. 반투명 배경·유리 효과를 사용하지 않는다.
- 눌림·비활성 상태는 opacity가 아닌 배경색·글자색으로 구분한다. 친구 아바타도 흐리게 표시하지 않는다.
- 버튼 변형은 primary / secondary / raised이며, raised는 그림 위에 배치하는 불투명 크림색 버튼이다.

## 목표 시간 색상 확정 — 2026-10-26

- 목표 시간 색상은 D1 핑크 `#FFA3A6`로 확정한다. 디자인 시스템의 `colors.goal`을 사용한다.
- 주간 기록의 목표 막대와 범례에 적용하며, 실제 공부 시간은 기존 초록색을 유지한다.
