# 친구 탭 연결 — 2026-10-27

- 스토리북 친구 목록 디자인을 앱 FriendsScreen에 반영. 캐릭터, 공부 상태, 서버 기준 초 단위 시간, 목표, 달성 배지, 구성원 수 표시.
- 기존 StudyProvider의 실시간 구독/주기 갱신/당겨서 새로고침 사용. 오류 시 마지막 현황을 표시하고 시간 증가를 멈춤. 로딩, 빈 목록, 재시도 처리.
- 구성원 선택 시 실제 데이터로 주간/월간 기록, 날짜별 합산 시간과 목표 표시. 세션별 상세를 서버가 제공하지 않으므로 가짜 세션을 생성하지 않음. 조회 범위는 최근 366일.
- get_member_history RPC: 입장 완료와 동일 방 확인, 최대 366일 제한, 기존 _day_record 재사용.
- 270_friend_history.sql을 원격 Supabase SQL Editor에 적용 완료. 기존 함수가 없는 것을 확인하고 이 파일만 실행함. CLI 마이그레이션 이력에는 별도 등록하지 않았으므로 중복 실행 금지.
- 서버 롤백 검사 통과: 본인과 같은 방 구성원 조회, 없는 구성원/다른 방/미인증 조회 거부, 366일 초과 범위 거부. 재현 파일: supabase/tests/friend_history.sql.
- lint, 타입 검사, 자동 테스트 53개, 웹 배포 빌드 통과. 기존 캐릭터 이미지 경로 문제가 해결된 상태에서 브라우저 검증 수행.
- Chrome 390×844와 320×740에서 실제 테스트 방 4명 목록 확인. 다른 구성원(홈테스트)의 1분 52초 기록이 목록/주간/월간/날짜별 상세에 일치. 이전 달 이동과 날짜 변경, 목록 복귀 확인.
- 테스트 방에서 공부 시작 → 친구 목록 공부 중 1명과 초 단위 시간 증가 → 해당 구성원의 기록 화면 연동 → 공부 중지 확인. 운영 방 사용자 기록은 편집하지 않음.
