# 얌얌스터디 화면별 기능과 사용 흐름

기준일: 2026년 10월 29일

상위 기준: [제품 명세](SPEC.md). 제품 목적과 기능 범위는 제품 명세에서, 정확한 제한·예외·공통 규칙은 [상세 기능 정책](FEATURE-POLICIES.md)에서 관리한다. 이 문서는 그 방향과 정책에 따른 화면의 진입 경로·표시 정보·조작 순서를 설명한다. 상세 정책 변경 시 관련 화면 설명을 함께 갱신하고, 제품 방향이나 기능 범위가 바뀌면 제품 명세도 갱신한다.

얌얌스터디는 소규모 스터디 구성원이 공부 시간을 기록하고, 친구의 공부 현황과 목표 달성 여부를 공유하며, 연차로 쉬는 날을 관리하는 앱이다. Android APK와 iPhone 웹앱을 제공한다.

이 문서는 현재 작업본에 구현된 사용자 화면과 조작을 정리한다. 화면별 진입 경로, 확인할 수 있는 정보, 실행할 수 있는 기능을 중심으로 설명한다. 운영에 배포된 버전과는 차이가 있을 수 있다.

## 전체 화면 구성

하단 메뉴는 **홈 · 기록 · 친구 · 연차 · 나**의 다섯 탭이다. 공부방과 목표 설정, 프로필 편집, 보유 스킨, 허용앱 설정, 이용 안내, 앱 정보는 별도 화면으로 열린다.

| 화면 | 진입 경로 | 주요 역할 |
| --- | --- | --- |
| 시작 및 입장 | 앱 실행 | 사용자 확인, 초대 코드 입력, 이름과 캐릭터 설정 |
| 홈 | 홈 탭 | 오늘 누적 시간과 목표 확인, 공부 시작, 공부방 입장 |
| 우리 공부방 | 홈에서 공부 시작 또는 공부방 입장하기 | 이번 집중 시간 측정, 친구 현황, 포스트잇, 친구 부르기 |
| 공부 목표 설정 | 홈의 오늘 목표 또는 나 탭 | 요일별 목표 편집과 미리보기 |
| 기록 | 기록 탭 | 내 주간·월간 기록과 날짜별 공부 내역 |
| 친구들 | 친구 탭 | 구성원별 현재 상태와 오늘 공부량 |
| 친구의 기록 | 친구 목록에서 구성원 선택 | 선택한 친구의 주간·월간 기록과 날짜별 내역 |
| 연차 | 연차 탭 | 사용 가능한 연차와 주간 보상 진척, 연차 일정 |
| 연차 달력 | 연차 사용하기 또는 연차 일정 선택 | 당일 사용, 미래 예약, 예약 변경과 취소 |
| 나 | 나 탭 | 프로필, 이번 주 달성 현황, 설정과 안내 진입 |
| 프로필 수정 | 나 탭의 프로필 편집 | 이름과 기본 캐릭터 변경 |
| 보유 스킨 | 나 탭의 보유 스킨 항목 | 선물 받은 스킨 확인과 적용·해제 |
| 허용앱 설정 | 나 탭 또는 허용앱 팝업 | Android 권한 설정과 공부 중 사용할 앱 선택 |
| 이용 안내 | 나 탭 | 공부 날짜, 출석, 목표, 연차 규칙 확인 |
| 앱 정보 | 나 탭 | 설치 버전과 업데이트 안내 확인 |

## 시작 및 입장 화면

앱을 실행하면 저장된 사용자 정보를 확인한다. 입장을 마친 사용자는 저장된 정보로 다시 들어가며, 신규 사용자는 초대 코드와 프로필 설정을 거친다.

- 실제 방은 초대 코드를 입력해 입장한다.
- 입장 후 친구에게 보일 이름을 1~12자로 설정한다.
- 이름 설정 단계에서 기본 캐릭터를 선택한다.
- 이름과 캐릭터는 나중에 프로필에서 바꿀 수 있다.
- 초대 코드 확인과 이름 저장 중에는 중복 제출을 막고, 실패하면 오류를 안내한다.
- 사용자 확인이나 초기 데이터 로딩에 실패하면 다시 확인할 수 있다.
- 개발용 테스트 방은 초대 코드 대신 `테스트로 입장하기`를 제공한다.
- 테스트 버전은 `테스트 설정`에서 0번 테스트 방과 1번 실제 방을 선택한다. 1번은 실제 기록이며 초대 검증을 거친다. 진행 중인 공부나 미확인 요청이 있으면 전환을 제한한다. 친구용은 1번 방으로 고정한다.

**사용 흐름:** 앱 실행 → 초대 코드 확인 → 이름과 캐릭터 설정 → 시작하기 → 홈.

별도 로그인 화면 없이 익명 사용자 정보로 기록을 구분한다. 기기 변경이나 앱 데이터 삭제 후 기존 기록에 접근하기 위한 사용자용 이전·복구 기능은 현재 제공하지 않는다.

## 홈 화면

오늘 공부 상황을 확인하고 공부를 시작하는 기본 화면이다.

- 오늘 전체 공부 시간을 시·분·초로 확인한다.
- 원형 버튼으로 공부를 시작하거나 일시정지한다.
- 홈에서 공부 시작에 성공하면 우리 공부방으로 이동한다.
- 오늘 목표 시간, 달성률 막대와 백분율을 확인한다.
- 목표를 달성하면 `달성 완료` 표시가 나타난다.
- 오늘 목표를 누르면 공부 목표 설정의 미리보기가 열린다.
- 연차일에는 `오늘 연차` 표시를 누르면 연차 탭으로 이동한다.
- 내 캐릭터와 적용한 스킨, 스킨에 연결된 효과를 보여준다.
- 공부 중인 친구가 있으면 인원과 캐릭터를 보여준다.
- `공부방 입장하기`로 우리 공부방을 연다.
- `허용앱`으로 내 허용앱 팝업을 연다.

**사용 흐름:** 오늘 목표와 누적 시간 확인 → 공부 시작 → 공부방에서 집중 → 일시정지 → 홈에서 하루 누적 확인.

`공부방 입장하기`는 화면 이동이며, 타이머 시작 버튼과 구분된다.

## 우리 공부방 화면

내 캐릭터와 친구 캐릭터가 같은 공부방에 앉아 있는 화면이다. 최대 네 자리의 공부방 배치를 보여준다.

- 중앙 타이머로 **이번 집중 시간**을 확인한다.
- 별도로 **오늘 누적 시간과 오늘 목표**를 확인한다.
- 오늘 목표 달성률과 달성 완료 표시를 보여준다.
- 공부를 시작하거나 일시정지한다.
- 내 이름표에는 `나`, 친구 이름표에는 친구의 누적 공부 시간을 표시한다.
- 구성원의 공부 중·쉬는 중 상태를 표시한다.
- 적용한 캐릭터 스킨과 효과, 목표 달성 연출을 보여준다.
- 포스트잇으로 공부방에 메시지를 남기고 읽는다.
- 쉬는 중인 친구의 이름표를 누르면 친구 부르기 창을 연다.
- 상단 허용앱 버튼으로 선택한 앱을 실행할 수 있다.
- 뒤로 가기로 홈에 돌아간다.

홈의 시간은 하루 전체 누적이고, 공부방의 큰 타이머는 현재 진행 중인 집중 구간의 시간이다. 일시정지 후 다시 시작하면 새로운 집중 구간을 측정한다.

### 공유 포스트잇

- `붙이기`를 눌러 최대 50자의 메시지를 작성한다.
- 노랑·분홍·연두 중 색상을 고른다.
- 공부방에서 붙일 위치를 눌러 배치한다.
- 붙어 있는 포스트잇을 누르면 작성자와 내용을 확인한다.
- 읽기 창에서 같은 방 친구의 포스트잇도 지울 수 있다.
- 같은 방의 포스트잇 변경 사항을 공유하며, 현재 공부 날짜의 포스트잇을 표시한다.

**사용 흐름:** 붙이기 → 내용과 색상 선택 → 붙일 위치 고르기 → 공부방에서 위치 선택 → 포스트잇 표시.

### 친구 부르기

- 본인을 제외한 쉬는 중인 친구의 이름표에서 실행한다.
- 기본 메시지 `같이 공부하자! 🍀`를 수정할 수 있다.
- 메시지는 최대 40자로 입력한다.
- 보내기 후 전송 요청 결과나 실패 이유를 안내한다.
- 전송 결과가 불확실하면 같은 요청의 결과를 다시 확인한다.
- 친구가 알림을 받으려면 해당 기기에서 친구 부르기 알림을 켜야 한다.
- 수신자 기준 5분에 한 번 전송할 수 있다.

전송 요청이 접수되어도 기기 설정에 따라 실제 알림 표시가 늦어질 수 있다.

## 공부 목표 설정 화면

홈의 오늘 목표를 누르거나 나 탭의 `공부 목표 설정`에서 들어간다.

- `요일별 설정`과 `미리보기`를 전환한다.
- 월요일부터 일요일까지 목표를 각각 설정한다.
- 시간 선택기로 목표 시간을 정한다. 0분은 쉬는 날이며, 미설정은 아직 목표를 정하지 않은 초기 상태다. 설정한 목표를 미설정으로 되돌리는 기능은 제공하지 않는다.
- 미리보기에서 일주일 목표와 합계를 확인한다.
- 저장 전 변경 사항과 적용 예정일을 표시한다.
- 첫 목표 저장은 오늘부터 적용하며, 오늘 이미 공부한 시간도 포함한다.
- 이후 변경은 다음 공부 날짜 오전 6시부터 적용한다.
- 저장하지 않고 나가려고 하면 편집을 계속할지 변경을 버릴지 확인한다.
- 저장 실패 시 입력한 목표를 유지하고 다시 저장할 수 있다.

**사용 흐름:** 요일 선택 → 목표 시간 설정 또는 0분으로 휴무 지정 → 다른 요일 편집 → 저장하기 → 적용 시점 확인.

## 기록 화면

내 공부 기록을 주간과 월간으로 살펴본다.

- `주간`과 `월간`을 전환한다.
- 이전·다음 기간으로 이동하며 미래 기간으로의 이동은 제한한다.
- 선택한 기간의 총 공부 시간과 목표 달성 일수를 확인한다.
- 주간 보기에서 실제 공부 시간과 목표 시간을 막대로 비교한다.
- 주간·월간 날짜의 수박은 목표 미달이어도 공부한 비율만큼 왼쪽 아래부터 사선으로 드러난다. 100%부터 완성 수박을 표시하며, 상세 기록의 달성 뱃지는 목표 달성 시에만 표시한다.
- 월간 보기에서 날짜별 공부 상태를 달력으로 확인한다. 서버가 확정한 7일 완주 주의 일요일은 금색 수박으로 표시하며, 상세 뱃지 문구는 ‘목표 달성’을 유지한다. 서버 마이그레이션 적용 전에는 일반 수박을 유지한다.
- 날짜를 누르면 아래에 상세 기록을 표시한다.
- 날짜별 실제 공부 시간, 목표, 달성률과 공부 구간 개수를 확인한다.
- 각 공부 구간의 시작 시각, 종료 시각과 공부 시간을 확인한다.
- 진행 중인 구간은 종료 시각 대신 `공부 중`으로 표시한다.
- 공부함·목표 달성·쉬는 날·연차·기록 없음의 표시 안내를 연다. 금색 수박의 7일 완주 조건도 이 인포 팝업 안에서만 안내한다.
- 저장된 기록을 먼저 보여줄 때는 최신 기록 확인 중임을 안내하며, 조회 실패 시 다시 불러올 수 있다.

**사용 흐름:** 기록 탭 → 주간 또는 월간 선택 → 기간 이동 → 날짜 선택 → 상세 공부 내역 확인.

현재 화면은 기록 조회를 제공한다. 사용자가 공부 시간을 직접 추가·수정·삭제하는 편집 기능은 제공하지 않는다.

## 친구들 화면

같은 방 구성원의 오늘 공부 현황을 목록으로 확인한다.

- 전체 구성원 수와 공부 중인 인원을 확인한다.
- 구성원별 이름, 캐릭터와 적용 스킨을 표시한다.
- 공부 중·쉬는 중·연차 사용 중 상태를 확인한다.
- 오늘 누적 공부 시간과 목표 시간을 확인한다.
- 목표가 있는 구성원의 달성률과 달성 완료 표시를 보여준다.
- 구성원을 누르면 해당 친구의 기록 화면을 연다.
- 연결 끊김이나 갱신 지연 시 마지막 확인한 현황임을 표시한다.
- 조회 실패 시 다시 불러올 수 있다.

### 친구의 기록 화면

선택한 친구의 기록을 내 기록과 같은 주간·월간 구성으로 확인한다.

- 기간별 총 공부 시간과 목표 달성 일수를 확인한다.
- 날짜를 선택해 목표, 공부량과 공부 구간별 내역을 확인한다.
- 뒤로 가면 친구 목록으로 돌아간다.

**사용 흐름:** 친구 탭 → 구성원 선택 → 주간·월간 전환 → 날짜별 상세 확인.

## 연차 화면

공부 목표를 면제받는 연차의 잔액과 일정을 확인한다.

- 사용 가능한 연차 개수를 확인한다.
- 사용 가능한 연차 중 가장 빠른 만료 날짜와 오전 6시 만료 시각을 표시한다.
- 이번 주 보상 인정 일수를 6일 기준으로 보여준다.
- 앞으로 예약한 연차와 오늘 사용 중인 연차를 일정 목록으로 확인한다.
- 일정 항목을 누르면 해당 날짜의 연차 달력이 열린다.
- `연차 사용하기`로 날짜 선택 화면에 들어간다.
- 안내 버튼으로 지급·사용·만료 규칙을 확인한다.
- 화면을 당겨 새로고침하거나 조회 실패 후 다시 불러온다.

### 연차 달력 화면

- 월을 이동하며 연차 사용일과 쉬는 날을 확인한다.
- 오늘 또는 미래 날짜를 선택한다.
- 오늘을 선택하면 `오늘 연차 사용`을 실행한다.
- 미래 날짜를 선택하면 연차를 예약한다.
- 미래 예약은 사용일 오전 6시 전에 날짜를 변경하거나 취소한다.
- 사용·변경·취소 전에 확인 창을 보여준다.
- 사용할 수 없는 날짜는 제한 이유를 안내한다.
- 만료가 빠른 연차부터 사용한다.
- 관리자 지급 연차는 구분해서 표시하고, 앱에서 변경하거나 취소하지 못하도록 한다.

**사용 흐름:** 연차 탭 → 연차 사용하기 → 날짜 선택 → 사용 또는 예약 확인 → 일정 확인.

### 연차 규칙

- 무료 연차는 매주 월요일 오전 6시에 1개 지급되며, 다음 월요일 오전 6시에 만료된다.
- 무료 자동 지급은 2026년 11월 2일 오전 6시부터 시작한다. 10월 26일 주간분은 별도 지시 전 지급하지 않는다.
- 한 주에 양수 목표를 6일 달성하면 보상 연차 1개를 받는다.
- 휴무·미설정·연차 사용일은 보상 인정 일수에서 제외한다.
- 보상 연차는 획득 주 시작일로부터 21일 뒤 오전 6시에 만료된다.
- 당일 사용한 연차는 취소하거나 변경할 수 없다.
- 이미 획득한 보상의 인정 일수가 6일 미만이 되는 당일 연차 사용은 제한한다.

## 나 화면

내 프로필과 이번 주 달성 현황을 보고 설정 화면으로 이동한다.

- 이름과 캐릭터를 확인한다.
- 이름 옆 편집 버튼으로 프로필을 수정한다.
- 보유 스킨 개수를 확인하고 스킨 목록을 연다.
- 월요일부터 일요일까지 이번 주 목표 달성 여부를 확인한다.
- 요일별 수박으로 목표 대비 공부량을 확인한다. 목표 미달은 부분 채움으로 표시하며, 연차·휴무·미설정·미래 날짜는 채우지 않는다.
- 연차 보상까지 남은 달성 일수를 확인한다.
- 공부 목표 설정으로 이동하고 현재 주간 목표 합계를 확인한다.
- 적용 예정인 목표가 있으면 적용 날짜를 표시한다.
- 허용앱 설정, 공부와 연차 이용 안내, 앱 정보로 이동한다.
- 친구 부르기 알림을 켜거나 끈다.

iPhone의 친구 부르기 알림은 Safari에서 홈 화면에 추가한 앱으로 열고 알림을 허용해야 사용할 수 있다. 알림을 눌러 앱에 들어오면 공부방으로 이동한다.

## 프로필 수정 화면

- 표시 이름을 수정한다.
- 토끼·곰·고양이·강아지·말티즈·포메라니안·검은고양이 중 기본 캐릭터를 선택한다.
- 저장하면 프로필과 공부방 현황을 갱신한다.
- 취소하거나 뒤로 가서 돌아갈 수 있다.
- 저장 실패 시 오류를 안내한다.

다른 기본 캐릭터로 변경하면 기존 스킨은 해제된다. 이름만 바꾸거나 같은 캐릭터를 선택하면 스킨을 유지한다.

## 보유 스킨 화면

- 현재 적용 중인 모습을 확인한다.
- 선물 받은 스킨 수와 캐릭터별 목록을 확인한다.
- 스킨 이름, 집중 모습 미리보기와 적용 여부를 확인한다.
- 보유 스킨을 선택하고 적용한다.
- 다른 캐릭터의 스킨을 적용하면 캐릭터도 함께 변경된다.
- `스킨 해제 · 기본 모습으로`를 눌러 기본 모습으로 돌아간다.
- 적용한 스킨은 홈과 집중 화면에 반영된다.
- 현재 앱에 이미지가 없는 스킨은 업데이트 필요 상태를 표시하고 적용을 제한한다.
- 목록 조회나 적용에 실패하면 오류와 재시도 기능을 제공한다.

현재 화면은 선물 받은 스킨의 보관과 적용을 제공한다. 수박 재화 획득·상품 구매·상점 기능은 포함하지 않는다.

## 허용앱 설정 화면

Android에서 공부 중 사용할 앱을 고르는 화면이다.

- 사용정보 접근과 알림 허용을 단계별로 안내한다.
- 필요한 기기 설정 화면으로 이동한다.
- 제한된 설정으로 권한을 켜기 어려울 때 도움말을 제공한다.
- 권한 설정을 마치면 설치된 앱 목록을 표시한다.
- 앱 이름으로 검색한다.
- 허용한 앱과 나머지 앱을 나누고 각 목록을 이름순으로 보여준다.
- 앱별 스위치로 허용 여부를 바꾸며 바로 저장한다.
- 공부 중에는 목록 변경을 제한한다.
- 선택한 목록은 현재 기기에 저장한다.

웹에서는 Android 전용 기능이라는 안내를 표시한다.

### 내 허용앱 팝업

홈과 공부방의 `허용앱` 버튼에서 연다.

- 등록한 허용앱을 아이콘과 이름으로 확인한다.
- 앱을 선택하고 열기 버튼으로 실행한다.
- 공부 중인 세션이 있고 필요한 권한을 갖춘 경우에 실행할 수 있다.
- 권한이 부족하거나 등록한 앱이 없으면 설정으로 이동한다.
- 목록 조회나 실행 실패 시 오류를 안내한다.

**사용 흐름:** 나 → 허용앱 설정 → 권한 허용 → 앱 선택 → 홈에서 공부 시작 → 허용앱 팝업 → 앱 실행.

### 플랫폼과 타이머 모드 차이

| 환경 | 공부 시간 동작 |
| --- | --- |
| 기본 타이머 | 허용앱 권한 없이 공부를 시작할 수 있다. 직접 일시정지할 때까지 경과 시간을 기록하는 방식이다. |
| Android 허용앱을 사용하는 공부 | 앱 안에서 연 허용앱을 사용하는 동안 시간을 기록한다. 홈 화면이나 다른 앱으로 이탈하거나 화면이 잠기면 일시정지하며, 돌아와 직접 재개한다. 다른 허용앱도 스터디앱으로 돌아와 실행한다. |
| iPhone 웹앱 | 허용앱 구분 기능을 제공하지 않는다. 다른 앱으로 이동해도 경과 시간을 누적한다. |

## 이용 안내 화면

- 하루가 한국 시간 오전 6시에 시작한다는 기준을 설명한다.
- 공부 시작과 일시정지, 기록 확인 방법을 설명한다.
- 출석과 목표 달성의 차이를 설명한다.
- 무료 연차와 보상 연차의 획득·사용·예약·만료 규칙을 설명한다.
- 기기 변경이나 저장소 삭제 시 기존 기록에 접근하지 못할 수 있음을 안내한다.

## 앱 정보 화면

- 설치된 앱 버전을 표시한다.
- 등록된 배포 정보를 바탕으로 업데이트 안내를 표시한다.
- 새 배포가 없거나 업데이트 안내 조건에 해당하지 않으면 설치 버전을 확인한다.

## 확인 기준

공부 날짜는 한국 시간 오전 6시부터 다음 날 오전 6시 전까지다. 새벽 공부와 연차의 오늘 판단, 기록의 날짜 구분에 같은 기준을 사용한다.

구현 근거는 `src/app/`의 화면 연결, `src/components/AdmissionGate.tsx`와 시작 화면, `src/features/` 아래의 study·goals·records·friends·leave·profile·allowed-apps·postits·call-friend 코드다. 개발용 Storybook 예시는 사용자 기능에 포함하지 않았다.
