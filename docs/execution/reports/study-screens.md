# 홈 · 집중 · 친구 화면

2026-10-26 사용자 참고 이미지를 바탕으로 크림색·초록색 화면과 공부방 일러스트를 적용했다.

- `/`: 본인 이름, 오늘 시간, 목표 진행률, 공부 중인 친구 요약, 시작/일시정지, 집중 화면 진입.
- `/focus`: 큰 타이머, 목표 잔여 시간, 공부 시작/일시정지, 홈/친구 이동.
- `/friends`: 실제 방 구성원과 본인, 공부 중/쉬는 중, 공부 시간·목표 진행률. 상태는 온라인 접속 여부를 의미하지 않는다.
- 하단 메뉴는 이번 범위인 홈·집중·친구로 구성했다. 기록·내 정보·설정·친구 초대는 포함하지 않았다.
- `StudyProvider`에서 기존 RPC와 실시간 세션 변경을 연결한다. 화면 표시 시계는 서버 스냅샷과 단조 시계로 계산하며, 06:00 경계를 넘으면 재조회한다. 복귀/가시성 변경/60초 간격의 활성 화면 조회로 동기화한다. 매초 요청이나 DB 쓰기는 하지 않는다.
- 시작은 기존 영속 멱등 요청을 사용한다. 실패한 시작/중지는 같은 작업으로 재시도하며, 중지 승인 전에는 시간이 계속 흐른다. 승인 직후 조회 실패 시에도 승인된 세션 상태를 먼저 적용한다.
- 휴무·목표 미설정은 달성률을 표시하지 않는다. 실패는 재시도로 안내하며 가짜 친구/공부 기록을 넣지 않았다.
- 일러스트는 ImageGen으로 만든 정적 장식이다. 그림 속 캐릭터 수나 행동은 실시간 인원/상태가 아니다. 아바타는 UID로 정해지는 기본 그림이며 선택 기능은 없다.

검증: 전체 린트·타입 검사, 자동 테스트 34개, 웹 내보내기 통과. 브라우저 390×844에서 홈→집중→친구 전환과 실제 조회 데이터를 확인했다. 기존 운영 기록을 변경하는 시작/중지 클릭 검증 및 Android/iPhone 실기기 검증은 하지 않았다. 연차 관련 기존 작업 파일은 수정하지 않았다.
