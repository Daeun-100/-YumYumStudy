# 03 — 친구 현황 (병렬 C)

선행: 00 병합. 소유: RoomScreen, useRoom, room 라우트, tests/room. 실제 Realtime은 01 연결 후 검증한다.

## 화면

- 고정 방 구성원 목록에 표시 이름, 본인 표시, 오늘 총공부 시간, 진행 중 세션 시간, 진행/휴식 상태를 표시한다.
- 동일한 이름이어도 UID로 항목을 구분한다. 4명을 하드코딩하거나 다른 UID를 숨기지 않는다.
- 목표가 있으면 달성률을 표시하고 없으면 미설정으로 표시한다.
- 내 연결이 끊기면 마지막 동기화 시각과 재연결 상태를 표시한다. 친구가 실제 공부하는지·온라인인지 보장하는 문구를 쓰지 않는다.

## 동기화

1. subscribeStudyChanges의 연결 완료 후 getRoom으로 snapshot을 받는다.
2. 시작·중지 알림을 받으면 전체 방을 재조회한다. 4명 규모이므로 복잡한 부분 갱신 저장소를 만들지 않는다.
3. 화면 표시용 시계 하나로 모든 행의 경과 시간을 계산한다. 매초 DB에 읽기/쓰기를 하지 않는다.
4. 조회 중 새 알림이 오면 한 번 더 조회해 누락을 막는다. 재연결·앱 복귀도 같은 경로를 쓴다.
5. unmount 시 구독/interval을 해제한다. 6시 경계에서 오늘 snapshot을 갱신한다.

## 검증 및 완료

- fixture로 시작·중지·늦은 조회 응답·중복 이름·6시 경계·빈 목록·통신 오류를 검사한다.
- DB 준비 후 A가 시작/중지할 때 B 화면이 새로고침 없이 갱신되는지 확인한다.
- A가 앱을 닫아도 B의 A 경과 시간은 올라간다. B가 재연결하면 DB의 최신 종료 상태로 보정된다.
- 린트·타입 검사 및 `reports/03.md`. 별도 Presence/heartbeat는 만들지 않는다.
