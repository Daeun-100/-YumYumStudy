# 기본 타이머와 앱 진입 복구

- 기본 타이머는 사용정보/알림 권한, 허용앱 선택 없이 시작한다. 권한이 모두 있고 허용앱이 선택된 경우에만 Android 감시를 준비한다.
- 기본 모드를 서버 시작 요청 전에 방/사용자별로 저장한다. 재시작하거나 시작 응답이 유실돼도 해당 공부를 감시가 끊긴 세션으로 오인해 종료하지 않는다.
- 로그인 확인 중이나 실패 시에도 앱의 홈/탭 화면을 표시한다. 확인된 초대 코드/이름 입력 단계만 입장 화면을 사용한다. 서버 인증과 방 권한 검사는 유지한다.
- 이전 시작 요청 복구는 IdentityProvider의 입장 조건에서 제거하고 StudyProvider의 별도 작업으로 이동했다. 기존 요청 ID 유지와 중복 요청 병합은 유지한다.
- 서버/기기 응답 대기에 제한을 두고 버튼 busy를 finally에서 해제한다. Supabase 통신은 실제 요청을 취소해 인증 잠금도 해제할 수 있게 한다.

검증: lint/typecheck 및 테스트 실행. 실제 Android 기기의 보고된 멈춤은 기기 로그를 확보하지 못해 재현 여부를 단정하지 않는다. 새 APK를 설치한 휴대폰 확인이 필요하다.

최종 검증: lint/typecheck 통과, 테스트 105개 통과. 로컬 웹 재진입 후 홈 표시 및 브라우저 오류 없음 확인. 새 ARM64 테스트 APK 빌드 성공(약 57.2 MiB), 패키지 com.yumyumstudy.app.test 및 서명 검증 통과. SHA-256: 1f2f98ac9676f9782688a0d6b2aa0569417edc12049f2502eaead62014a3cc3a. 로컬 컴파일로 클라우드 빌드 할당량 미사용. 기기에 자동 설치하거나 웹 배포하지 않았다.
