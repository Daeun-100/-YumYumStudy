- 확인일: 2026-10-30 한국 시간.
- 요청: 이벤트와 독립된 주제별 폴더·파일 경로로 에셋을 관리하고 여러 이벤트가 재사용한다. 이미지 버전 UUID 폴더를 새로 만들지 않는다.
- 상태: 코드·서버 전환과 실제 Storage 검증 완료. 테스트 앱 업데이트 게시 완료.

## 새 파일 구조

```text
event-artwork/
├─ halloween/backgrounds/
│  ├─ home.png
│  └─ focus.png
└─ winter/skins/bungeoppang-bunny/
   ├─ home.png
   └─ focus.png
```

- 라이브러리 배경 참조 ID `qa-remote-room`, 스킨 보유 ID `qa-remote-bunny`를 유지했다.
- 같은 PNG를 새 주제별 경로에 복사한 후 공개 다운로드의 바이트 크기·SHA-256을 검사했다. 기존 효과 설정과 캐릭터 연결도 보존했다.
- 마이그레이션 `20261029160457_themed_artwork_library`를 공유 Supabase에 반영했다. `private.artwork_library`에 theme·경로·규격·해시와 표현 정의를 등록하고 종류+참조 ID, 주제 조회 인덱스를 둔다.
- 새 정의는 schemaVersion 2이며 이미지 revision 필드가 없다. 등록 상태와 기존 지급·배경 활성 상태를 구분하고, 등록만으로 새 행사·지급을 실행하지 않았다.
- 이전 스킨 보유 16건, 과거 이벤트 기록과 기존 UUID 경로 PNG 4개를 유지했다. 당시 활성 예약은 0건이었다.

## 동작과 호환성

- 준비/업로드/검증 후 라이브러리에 직접 등록한다. 새 UUID를 발급하거나 초안·리비전 게시를 거치지 않는다.
- 배경은 주제 에셋을 참조하고 다른 이벤트에서도 같은 배경을 선택할 수 있다. 라이브러리 수정은 참조 이벤트에 함께 반영된다. 과거 예약의 이미지 리비전 필드는 이력 호환용으로 보존한다.
- 스킨은 기존 보유·착용 ID를 유지한다. 같은 파일명의 수정본은 해시를 포함한 URL로 캐시를 구분한다. 기본적으로 새 파일명을 권장하고 명시적 요청에서만 덮어쓴다.
- 새 앱은 `p_schema_version: 2`를 명시한 RPC로 주제별 경로를 받는다. 이전 인자의 RPC는 기존 정의/기본 이미지를 반환한다. 새 네이티브 의존성·앱 버전 변경은 없다.
- 배경 전환용 타이머는 추가하지 않는다. Realtime과 재연결·화면 재진입·앱 복귀 조회를 유지한다.

## 검증

- lint·typecheck·자동 테스트 383개 통과.
- 격리 DB의 주제 라이브러리·기존 원격 이미지·이벤트·스킨·지급 알림 검증 통과. Vault·HTTP·Cron·Storage 메타데이터는 대체 구현이며 실제 PNG 읽기는 별도 검증했다.
- 주제·종류에 맞는 경로 검증, 외부/상위 경로 거부, 기존 스킨 캐릭터 변경 거부, 보유·같은 방 착용·다른 방 차단, 직접 테이블·운영 RPC 접근 차단을 확인했다.
- 실제 SQL 사용자 역할로 스킨 v2 주제 경로와 v1 기존 정의를 확인했다. 배경 예약은 한 트랜잭션에서 생성해 v2 경로·v1 기본 대체를 확인한 후 롤백했다. 테스트 예약·Cron은 남기지 않았다.
- Android/iPhone 실제 이미지 표시·업데이트 적용은 사용자 기기 확인 전이다.
