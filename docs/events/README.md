# 이벤트 기록

이벤트별 기획, 준비 자료, 실제 운영과 결과를 한 문서에 남긴다. 선물 지급뿐 아니라 수집·교환 활동, 소품, 효과 아이템, 배너, 화면 연출 등도 함께 기록한다.

예약 기능의 이번 구현 범위와 채팅 운영 절차는 [이벤트 기록과 예약 운영 명세](../proposals/EVENT-OPERATIONS-SPEC.md)를 따른다. 실제 명령과 검증·반영 현황은 [운영 문서](../operations/EVENT-OPERATIONS.md)를 확인한다.

## 작성 방법

1. [템플릿](TEMPLATE.md)을 복사해 `YYYY-MM-DD-event-name.md`로 만든다. 날짜는 시작 예정일이며, 미정이면 `undated-event-name.md`로 시작한다.
2. 이벤트 ID는 `2026-halloween`처럼 연도와 이름으로 정하고, 파일명이나 일정이 바뀌어도 유지한다. 다음 해 행사는 새 ID와 문서를 만든다.
3. 개요와 필요한 구성만 먼저 작성한다. 해당하지 않는 항목은 지우고, 미정인 내용은 미정으로 남긴다. 구성 종류는 자유롭게 추가한다.
4. 이미지와 캡처는 `assets/<이벤트 ID>/`에 보관하고 문서에서 상대 경로로 연결한다. 실제 앱 에셋은 기존 에셋 위치를 링크해도 된다.
5. 아래 목록에 문서를 추가한다. 운영 후에는 실제 진행 내용, 결과, 다음에 참고할 점을 갱신한다.

모든 날짜와 시각은 별도 표기가 없으면 한국 시간(Asia/Seoul)이다. 개인별 활동·재화·지급 원본 데이터와 개인정보, 서버 비밀 키는 이 폴더에 저장하지 않는다. 문서에는 집계와 서버 기록 참조를 남긴다.

문서 작성만으로 실행 예약이나 앱 기능이 생성되지는 않는다. 실제 서버 예약을 확인한 뒤 예약 ID와 확인 시각을 기록한다. 실행 결과 역시 서버 기록이나 실제 확인을 근거로 작성한다.

종료 후에는 당시 규칙과 이미지를 보존한다. 후속 아이디어는 회고에 적고, 재개최는 이전 문서를 연결한 새 문서로 작성한다.
