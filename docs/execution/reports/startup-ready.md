# 초기 화면 준비 완료 후 진입

- 로그인·프로필, 오늘 공부 기록과 목표, 친구 현황, 이전 시작 요청 복구를 확인한 뒤 홈/집중 화면을 공개한다.
- 화면은 덮개 아래에서 먼저 마운트해 레이아웃을 측정하고, 현재 참여자의 홈·집중 캐릭터와 배경 이미지 로딩까지 완료한다.
- 준비 전 콘텐츠는 입력과 스크린리더에서 숨긴다. 준비된 화면 공개 후의 갱신은 전체 로딩을 다시 띄우지 않는다.
- 준비 중에는 로고/스피너만 표시한다. 20초 초과 또는 오류 시 같은 화면에서 재시도하며 초대 코드·이름 설정은 기존 입장 흐름을 유지한다.
- Android 이미지 페이드로 캐릭터가 늦게 나타나는 효과를 제거했다.

검증: 코드 검사·타입 검사·자동 테스트 107개 통과. 로컬 웹 홈/집중 화면에서 로딩 → 준비 완료 화면을 확인했다. 로컬 ARM64 테스트 APK 빌드와 서명 검증 통과(SHA-256 c3dd334b6d280c5e292ba1031954e5f235c35c9327088b6c83049207ea0f482c). 휴대폰에서 새 초기 로딩 동작의 최종 확인은 별도 필요하다.
