# 기록 탭 실제 데이터 연결

- 기존 Storybook RecordsPreview와 같은 주간 차트, 월간 달력, 요약, 범례를 사용하고, 선택한 날짜의 상세 기록은 차트·달력 아래에 표시한다.
- 최초 조회는 현재 공부 날짜가 포함된 주간이다. 주/월 이동 시 get_history로 해당 범위만 조회한다. 과거 기록은 기간 제한 없이 이동하고 미래 날짜는 선택할 수 없다.
- 본인 상세 기록은 인증된 UID와 현재 방으로 study_sessions를 필터링해 읽는다. 500개 단위 페이지 조회 및 15초 제한을 적용한다. DB 변경은 없다.
- 세션은 KST 오전 6시 경계로 분할하고, 진행 중 세션과 일별 확정 합계는 기존 displayedSeconds 규칙에 따라 표시한다.
- 현재 목표 대신 날짜별 목표 스냅샷을 사용하고 미설정/휴무/연차를 구별한다.
- 로딩, 빈 기간, 조회 실패, 재시도, 당겨서 새로고침을 제공한다. 이전 기간의 늦은 응답은 무시한다.
- 친구 기록에서도 서버 응답 정렬과 관계없이 가장 이른 날짜를 계산하도록 수정했다.

검증: Expo lint, TypeScript noEmit, 53개 단위 테스트, 웹 export 통과. 세션 상세 테스트에는 오전 6시 분할, 진행 중 초 단위 표시, 범위 밖 제외가 포함된다.

브라우저 통합 검증: 테스트 방 0에서 테스트 프로필 `기록 확인`으로 11초 공부를 시작/종료한 후, 기록 탭 상세의 합계 00:00:11과 실제 세션 01:21:55–01:22:06 일치를 확인했다. 주간/월간 전환, 미래 날짜 비활성화, 빈 상세 조회도 확인했다. 검증 화면은 docs/images/records-connected-verified.png에 저장했다.

빌드 검증 과정에서 dist의 번들 JS까지 타입 검사에 포함되던 문제를 tsconfig.exclude로 해결했다. 현재 파일명과 맞지 않던 포메라니안 홈/집중 이미지 참조도 현재 존재하는 파일명으로 맞췄다.

상세 표시 방식 변경: 상세 모달을 제거하고 기본 선택 날짜의 기록을 화면 아래에 바로 표시한다. 다른 날짜를 선택하면 같은 영역의 내용이 변경된다. 기록 표시 안내는 기존 안내 창을 유지한다.
