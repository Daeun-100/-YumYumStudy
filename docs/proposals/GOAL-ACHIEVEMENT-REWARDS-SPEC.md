# 목표 달성 보상 명세

작성일: 2026년 10월 29일  
상태: 구현 작업본 · 서버 마이그레이션 및 앱 배포 전  
대상: Android 앱과 iPhone 웹앱

하루 목표 달성은 일반 수박으로, 주 6일 달성은 보상 연차로, 연차 없는 한 주 완주는 금색 슈퍼 수박으로 보상한다. 이번 범위는 보상 판정과 표시이며, 수집·소비 기능은 제외한다.

현재 동작은 [상세 기능 정책](../product/FEATURE-POLICIES.md)을 기준으로 확인한다. 이 문서는 후속 구현 기준이며, [수박 보상과 꾸미기 시안](WATERMELON-REWARDS-DRAFT.md)의 추가 수박 보너스·상점·수집 구성을 이번 범위에 적용하지 않는다. [성취 알림 명세](IN-APP-CELEBRATION-SPEC.md)는 별도 작업이며 이번 범위에 금색 수박 전용 알림을 추가하지 않는다.

## 1 보상 기준

| 보상 | 지급 조건 | 지급량 |
| --- | --- | --- |
| 일반 수박 | 연차 사용일을 제외한 하루 목표 달성 | 하루 1개 |
| 보상 연차 | 같은 주에 연차 사용일을 제외한 6일 목표 달성 | 주당 1개 |
| 슈퍼 수박 | 연차 없이 월~일 7일 모두 목표 달성 | 주당 1개 |

슈퍼 수박을 받는 날에는 일반 수박을 지급하지 않는다. 해당 날짜의 보상을 슈퍼 수박으로 대체한다.

7일 완주한 주의 결과는 **일반 수박 6개 + 슈퍼 수박 1개 + 보상 연차 1개**다. 연차나 슈퍼 수박을 얻더라도 앞선 날짜의 수박은 차감하지 않는다.

## 2 날짜와 목표 달성 판정

- 하루는 한국시간 오전 6시부터 다음 날 오전 6시 전까지다.
- 한 주는 월요일 오전 6시부터 다음 월요일 오전 6시 전까지다.
- 각 공부 날짜에 적용된 양수 목표를 인정 공부 시간으로 채우면 달성이다.
- 진행 중인 공부 시간도 기존 목표 판정 규칙에 따라 포함한다.
- 휴무·목표 미설정은 달성으로 인정하지 않는다. 해당 날짜가 있는 주에는 슈퍼 수박을 받을 수 없다.
- 연차 사용일은 목표를 달성해도 보상 인정 일수에서 제외한다. 실제 공부 시간과 목표 달성 기록은 유지한다.
- 주간 보상은 날짜별 달성 여부로 판정한다. 하루에 목표를 초과 달성해도 여러 날로 계산하지 않는다.

## 3 연차와의 관계

- 무료·보상 연차를 획득하거나 보유하는 것은 슈퍼 수박 조건에 영향을 주지 않는다.
- 해당 주에 실제로 사용한 연차가 있으면 슈퍼 수박을 받을 수 없다. 무료·보상·관리자 연차 모두 포함한다.
- 다음 주 연차 예약은 이번 주 판정에 영향을 주지 않는다.
- 미래 연차 예약을 사용일 전에 취소했다면 연차 사용일로 계산하지 않는다.
- 보상 연차의 사용·예약·만료는 기존 정책을 유지한다.

## 4 보상 확정과 중복 방지

- 일반 수박은 해당 날짜의 목표 달성이 확인되면 반영한다.
- 보상 연차는 같은 주의 6번째 인정 달성일에 지급한다.
- 슈퍼 수박은 일요일 목표 달성으로 7일 완주가 확인되는 즉시 반영한다.
- 슈퍼 수박 지급일에는 일반 수박을 별도로 지급하거나 중복 표시하지 않는다.
- 보상은 서버 기록을 기준으로 확정한다. 축하 화면 확인이나 버튼 선택은 지급 조건이 아니다.
- 재접속·재조회·여러 기기 동시 사용으로 보상을 중복 지급하지 않는다.
- 앱 미실행 중 달성한 경우 다음 조회에서 확인해 누락된 보상을 반영한다.
- 보상 판정과 중복 방지에 필요한 내부 데이터는 유지하되, 별도 수집 기능으로 제공하지 않는다.

## 5 보상 획득 후 연차 사용

기존 보상 보호 정책을 슈퍼 수박에도 적용한다.

- 당일을 연차로 변경하면 이미 충족한 보상 조건이 깨지는 경우, 당일 연차 사용을 제한한다.
- 조건은 충족했지만 아직 보상 조회를 하지 않은 경우에도 같은 규칙을 적용한다.
- 슈퍼 수박을 획득한 일요일에는 당일 연차로 변경할 수 없다.
- 관리자가 사후에 연차를 적용하는 경우, 기존 운영 원칙에 따라 이미 지급한 보상은 회수하지 않는다. 미지급 보상은 변경된 기록으로 판정한다.

## 6 보상 표시

- 일반 수박과 슈퍼 수박은 각각 별도의 이미지 에셋을 사용한다.
- 슈퍼 수박에는 확정한 금색 수박 에셋 `assets/icons/watermelon-icon-gold.png`을 사용한다.
- 주간 화면에서 월~일 달성 상태와 6일 보상 연차·7일 슈퍼 수박 조건을 안내한다.
- 7일 완주 시 해당 날짜에는 일반 수박 대신 금색 슈퍼 수박을 표시한다.
- 접근성 설명에서도 ‘일반 수박’과 ‘슈퍼 수박’을 구분한다.
- 연차·휴무·목표 미설정·미달 상태는 기존 구분을 유지한다.

누적 획득 개수, 수집함, 별도 보상 획득 내역 화면은 제공하지 않는다.

## 7 안내 위치와 뱃지 문구

- 금색 수박의 의미와 획득 조건은 기록 화면의 기존 인포 아이콘을 눌러 여는 ‘기록 표시 안내’ 안에서만 설명한다.
- 주간·월간·달력·마이페이지 화면 밖에 금색 수박 전용 설명 행이나 완주 문구를 추가하지 않는다.
- 금색 수박을 사용하는 상세 뱃지의 문구도 ‘목표 달성’을 유지한다.
- 금색 수박 전용 축하 토스트나 별도 팝업은 이번 구현에 추가하지 않는다. 기존 성취 알림 기획은 별도 작업이다.

## 8 대표 사례

| 주간 결과 | 일반 수박 | 슈퍼 수박 | 보상 연차 |
| --- | ---: | ---: | ---: |
| 5일 달성 + 2일 미달 | 5개 | 없음 | 없음 |
| 6일 달성 + 1일 미달 | 6개 | 없음 | 1개 |
| 6일 달성 + 1일 연차 | 6개 | 없음 | 1개 |
| 6일 달성 + 1일 휴무·미설정 | 6개 | 없음 | 1개 |
| 연차 없이 7일 모두 달성 | **6개** | **1개** | **1개** |

위 개수는 해당 주의 보상 결과를 설명하며, 누적 잔액 화면을 의미하지 않는다.

## 9 개발 범위와 검증 기준

이번 범위에 포함한다.

- 일반 수박·보상 연차·슈퍼 수박 판정과 반영
- 중복 방지와 누락 보상 복구
- 별도 금색 수박 에셋 적용
- 주간 달성 상태와 보상 조건 표시
- 기존 인포 팝업 안의 금색 수박 안내와 ‘목표 달성’ 뱃지 문구 유지

다음 기능은 제외한다.

- 수집함·누적 개수·별도 보상 획득 내역 화면
- 수박 소비·교환·상점·아이템 구매
- 선물·양도

구현 완료 시 다음을 확인한다.

- 7일 완주 결과가 일반 수박 6개와 슈퍼 수박 1개로 반영되는지
- 연차·휴무·미설정 날짜가 있으면 슈퍼 수박이 지급되지 않는지
- 6일 달성 보상 연차는 기존 규칙대로 지급되는지
- 날짜·주간 경계, 재접속, 동시 조회에서 판정과 지급이 일관되는지
- 금색 수박이 Android 앱과 iPhone 웹앱에서 정상 표시되고 접근성 설명으로 구분되는지

실제 구현 시 lint와 typecheck를 실행하고, Android 실기기와 iPhone 웹앱의 표시를 확인한다. 확정 에셋과 화면 연결, 서버 판정 마이그레이션을 구현했다. 운영 서버 적용과 앱 배포, 네이티브 실기기 검증은 별도다.
