# 미연결 UI 마무리

## 목표 설정

GoalsView를 앱과 Storybook에서 공유한다. 요일별 편집, 시간 휠, 휴무 전환, 주간 미리보기, 일괄 저장, 미저장 이탈 확인을 실제 목표 API에 연결했다. 편집 확인은 로컬 초안만 바꾸고 하단 저장하기에서 서버에 반영한다.

사용자 후속 요청 반영: 공부 시간 설정하기/목표 미설정으로 두기 버튼을 제거했다. 미설정인 요일도 편집창을 열면 즉시 시간 휠이 나온다. 미설정은 아직 처음 설정하지 않은 요일에만 남고, 편집 확인은 양수 시간이나 휴무만 선택한다. 미설정(null)인 다른 요일을 일괄 저장 과정에서 휴무(0)로 바꾸지 않는다. 기존 분 단위 목표도 반올림 없이 보존한다.

저장 직전 서버 설정을 재조회하고 초안에서 편집한 요일만 병합한다. 다른 요일의 최신 값은 보존한다. 이는 최신 조회 기준 병합이며 API에 새 예약 버전/잠금을 추가한 것은 아니다. 저장 응답의 실제 적용일을 표시한다. 실패 시 초안은 남고, 재조회로 저장을 확인한 경우 완료 상태를 복구한다. Expo Router usePreventRemove로 앱 뒤로가기 및 웹 이탈을 보호한다.

브라우저 테스트 방 0: 월요일 90분·화요일 휴무를 편집/일괄 저장하고 2026-10-27 06:00 적용일 확인, 새로고침 후 복원 확인. 미저장 이탈 확인/계속 편집/주간 미리보기 검증. 테스트 후 기존 미설정 값으로 복원 저장했다. 후속 UI 변경 이후 바로 시간 휠 노출, 미설정 복원 버튼 부재, 0시간 확인 거부를 확인했다.

## 친구 기록

최근 366일 일괄 조회를 주/월 범위별 조회로 바꾸어 1년 이전도 이동한다. 기존 get_member_history로 같은 방의 조회 가능 회원인지 확인한 뒤, 기존 study_sessions RLS와 현재 방 필터로 실제 세션 목록을 조회한다. DB 권한/함수 변경은 없다. 본인과 친구 상세는 같은 표시 컴포넌트를 쓰며 KST 06:00 분할, 진행 중 표시, 실패/재시도 규칙을 공유한다.

브라우저의 다른 테스트 회원에서 34초+78초=112초(00:01:52), 실제 시작·종료 시각 두 건을 확인했다. 월간 2025년 9월까지 이동해 1년 이전 범위와 빈 기록 표시도 확인했다.

## 공통 업데이트 안내

UpdateProvider를 앱 공통 루트에 한 번만 두고 실행/복귀 시 조회한다. 새 배포가 있으면 모든 탭과 상세 화면에서 공통 안내를 표시한다. 앱 정보는 같은 상태를 공유하므로 중복 조회/중복 안내를 만들지 않는다. 나중에 선택한 버전은 화면을 옮겨도 숨김을 유지한다. 사용 중 주기적 조회를 추가하지 않았다.

개발 테스트 방에서는 기존 정책대로 실제 배포 조회를 생략한다. 운영 배포 정보를 새 버전으로 활성화하거나 APK를 다운로드/설치하는 검증은 하지 않았다. 기존 배포 조회/버전 비교/응답 검증 단위 테스트와 앱·스토리북 빌드로 연결을 확인했다.
