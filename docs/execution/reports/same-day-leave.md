## Storybook 확정 UI 반영 — 2026-10-27

- 홈의 별도 연차 설명 줄을 제거하고 기존 목표 줄을 ‘오늘 연차’ 링크로 전환했다. 링크는 Expo Router로 연차 탭 메인에 이동하며 실제 목표 달성 배지는 유지한다.
- 연차일의 진행 막대 바탕은 `colors.leaveTrack`(#4E89C4), 채움은 기존 초록색이다. 진행률이 100% 이상이면 채움이 바탕을 모두 덮는다.
- 오늘 사용과 모든 미래 예약을 하나의 연차 일정 목록으로 통합했다. 비행기는 오늘 글자 오른쪽, 날짜들은 같은 왼쪽 선으로 정렬한다. 일정 행은 해당 날짜가 선택된 실제 달력을 열며 기존 사용/예약 관리 기능을 유지한다.
- 보상 인정 일수와 연차 일정 제목은 원래 보상 제목 기준인 16px/700으로 통일하고 날짜는 16px/보통 굵기로 표시한다. 스토리북과 실제 앱은 일정 목록 컴포넌트와 색상 토큰을 공유한다.
- 로컬 실제 앱에서 홈→연차 탭→오늘 달력→연차 메인의 왕복과 USED 취소/변경 버튼 부재를 확인했다. 실제 사용자 연차를 추가 사용하거나 취소하지 않았다. 린트·타입 검사, 전체 167개 단위 테스트, 웹 내보내기가 통과했다. APK 배포는 별도다.
